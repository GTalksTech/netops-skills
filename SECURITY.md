# Security

## Report a problem privately

If you find a way a skill could leak credentials, run a command it shouldn't, or change a device
it was told only to read, please don't open a public issue. Report it privately instead:
[open a security advisory](https://github.com/GTalksTech/netops-skills/security/advisories/new).
I'll reply within a week.

## Keep your network private

Snapshots and reports hold real configs. Before you paste anything into an issue, PR or
discussion, redact hostnames, IP addresses, usernames, passwords, keys and SNMP communities.
Keep your snapshot repo private.
